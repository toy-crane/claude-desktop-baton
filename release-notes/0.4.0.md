Remote Control sessions now follow an account switch.

- **Remote Control sessions follow you.** Sessions run by a Remote Control server (`claude remote-control`) are listed by the account that started the server, so until now they were missing after a switch. After a switch, the app opens each running one in Claude, the way Claude Code's `/desktop` command does, so it is listed under the new account. From then on it follows every switch like any other session. The first switch after starting such sessions opens each of them in Claude once.
- **`status` lists them.** `claude-desktop-baton status` shows the Remote Control sessions running on this Mac (`remoteControlSessions` with `--json`).

**Use a Remote Control session from one place at a time.** After it opens in Claude it keeps running under its server too, and two programs writing the same conversation can damage it.
