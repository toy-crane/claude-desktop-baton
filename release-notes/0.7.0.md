Accounts in name order, and the ones out of weekly limit set apart.

- **Find accounts by name.** The accounts you can switch to are now listed by name, the way Finder sorts files, so "Work 2" comes before "Work 10". The command line's `accounts` and the Remove account menu use the same order.
- **See which accounts you can use now.** An account whose weekly limit is used up moves to a short **Week limit reached** group at the bottom of the panel, one line each with when its limit resets. It moves back as soon as the limit resets. You can still switch to it with a click.
